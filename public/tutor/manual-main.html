1. ペラトレとは

🎯 サービスコンセプト

ペラトレは、「英語がペラペラ話せるようになるトレーニング」を提供する英会話スクールです。

🔑 重要な特徴
• 受講生の99%が英会話初心者
• マンツーマンレッスンで丁寧に指導
• 実践的な会話力の習得を重視
• 継続しやすいサポート体制

🎓 受講生の特徴

  • 英会話レベル：初心者〜中級者が中心
  • 年齢層：20代〜50代と幅広い
  • 目的：日常会話、旅行、ビジネスなど多様
  • 学習スタイル：オンラインでの自己学習+レッスン

2. レッスンの基本情報

⏰ レッスン時間

全てのレッスン：50分

✅ レッスン時間の統一
全レッスンが50分で統一されています。初回も2回目以降も同じ時間です。

📋 レッスンの流れ

  1. 前回の復習（5分） - 前回のレッスン内容を振り返り
  2. 本日の目標確認（3分） - 今日学ぶ内容を明確化
  3. メインレッスン（35分） - 教材を使った実践練習
  4. フィードバック（5分） - 良かった点・改善点を共有
  5. 次回の予告（2分） - 次回の内容を簡単に案内

🎯 レッスンの目的

ペラトレのレッスンは、以下の3つを重視します：

  • 実践練習の場 - 学んだことを実際に使ってみる
  • フィードバックの提供 - 発音や表現を改善するアドバイス
  • モチベーション維持 - 成長を実感できる褒めと励まし
⚠️ 重要
レッスンは「新しく教える場」ではなく、「練習とフィードバックの場」です。基本的な学習は受講生が自習で進めています。

3. 教材・進め方の方針

📚 使用教材

受講生は以下の教材を使用しています：

  • チャンク学習教材 - 基本的な英語表現の習得
  • 瞬間英作文 - 日本語→英語の変換練習
  • シャドーイング教材 - リスニング・発音強化
  • オリジナル会話教材 - 実践的な会話練習
💡 教材の進め方
• 受講生は事前に自習で教材を学習しています
• レッスンでは実践練習とフィードバックを行います
• 進度は受講生のペースに合わせます（無理に進めない）
• Googleドキュメントでリアルタイムに添削・メモを残します

🎓 指導方針

  • 褒めて伸ばす：できたことを積極的に褒める
  • 丁寧な添削：発音・文法の細かい改善点も指摘
  • 実用性重視：実際の会話で使える表現を優先
  • 継続を応援：小さな成長も認めてモチベーションを維持

✏️ 添削のポイント

✅ 効果的な添削方法
1. 即座に修正 - 間違いはその場で優しく訂正
2. 理由を説明 - なぜその表現が良いのか簡潔に説明
3. 繰り返し練習 - 正しい表現を何度か練習させる
4. Googleドキュメントに記録 - 後で復習できるようにメモ

4. MasaEnglishとの違い

ペラトレとMasaEnglishは別サービスです。違いを理解しておきましょう。

🔄 主な違い

項目 ペラトレ MasaEnglish
対象者 英会話初心者が中心 より幅広いレベル
レッスン形式 マンツーマン50分 グループ・マンツーマン混在
教材 初心者向けに特化 多様なレベルに対応
サポート より手厚いフォロー 標準的なサポート
⚠️ 注意点
• レッスン方法や教材は混同しないように注意してください
• 受講生からの質問にはペラトレの方針で回答してください
• 不明な点は運営に確認してください

5. 報酬・スケジュール

💰 報酬体系

✅ レッスン報酬

2,000円（50分）

内訳：

  • 基本報酬：1,800円
  • 前日リマインド：+100円
  • Zoomリンク共有：+100円
💡 追加報酬について
運営から義務付けられた依頼（レッスンメモ作成、Googleドキュメント準備など）については、別途報酬が発生します。

🔄 引き継ぎについて

Q. レッスンで引き継ぎはありますか？

A. はい。

  • 講師はレッスンメモを記入してください
  • 受講生まとめシートの「レッスンドキュメント欄」に「どこまでやったか」を残します
  • 万一記入が漏れても、レッスン録画やメモが必ず残っているので確認可能です
👉 前回のレッスン内容はレッスンメモを確認してください。「前回どこまでやったか」「どんな添削をしたか」を踏まえて続きから行います。毎回ゼロから始めることはありません。

📅 レッスンスケジュール

  • レッスン予約：受講生が希望日時を選択
  • 前日リマインド：講師から受講生へSlackで連絡
  • Zoomリンク：レッスン前日までに共有
  • レッスン後：24時間以内にフィードバック・メモを記入
