📖 レッスンについて

📅 スケジュール・勤務条件

講師や生徒は固定ですか？
+
受講生が選択できます。

• 固定を希望される場合：同じ講師が継続して担当
• その都度選びたい場合：毎回異なる講師も可能

※他の講師がお休みなどで対応できない場合には、別の生徒さんを担当いただくこともあります。
勤務可能時間は何時から何時までですか？
+
基本的には9:00〜23:00の間でお願いしております。
日程変更したいとき、どれぐらい前までに連絡すればいいですか？
+
基本的には1週間前までに連絡してください。
講師側から日程変更を提案できますか？
+
はい、可能です。受講生と相談の上、調整してください。
契約期間はどのくらいですか？
+
契約期間は1年間です。

👥 受講生について

生徒さんの情報は、事前にどの程度わかりますか？
+
生徒さんとの契約が始まり次第、アンケート調査を行いますのでその内容を共有させていただきます。
どのようなレベルや目的を持った生徒さんが多いですか？
+
ある程度の英文法は理解しているものの、アウトプットの機会が少ない方が多いです。そのため、英会話レベルでいうと初心者の方が中心となります。
受講生との連絡手段は？
+
公式LINEアカウントを通じてやり取りします。

個人LINE・SNSでの直接連絡は禁止です。すべてのコミュニケーションは公式LINEを経由してください。
受講生から個人LINEで連絡が来た場合は？
+
「すべてのやり取りは公式LINEでお願いします」と丁寧にお伝えし、公式LINEへ誘導してください。

個人的な連絡先の交換は、トラブル防止のため固くお断りしています。

📚 レッスン準備・内容

レッスンで使用する教材はありますか？
+
予習マニュアルと復習マニュアルがあります。
受講生におすすめの教材はありますか？
+
はい、市販教材のおすすめリストを用意しています。

受講生から「何を勉強したらいいですか？」と聞かれた際に、以下のリストを紹介してください。

• 文法：中学英文法の総復習
• 発音：音声変化のルールを学べる本
• 語彙：会話の型で覚える本
• リスニング：TED / BBC / Netflixなど

🎓 おすすめ教材リストを見る
レッスンの時間配分は？
+
50分レッスンは「ウォームアップ（8〜10分）」「メイントレーニング（25〜30分）」「振り返り+まとめ（約10分）」が目安です。

生徒の状態や会話の流れに合わせて柔軟に調整してください。

詳しくはレッスンの進め方ページをご覧ください。
レッスンの引き継ぎはどうすればいいですか？
+
前回のレッスン内容は全体のレッスン状況シートにある「保存フォルダ」か受講生別「ポータルサイト」から確認してください。

🎯 レッスン進行・指導方法

英語だけでレッスンを行うのでしょうか？それとも日本語も使いますか？
+
生徒さんのレベルに合わせて、英語と日本語を使い分けていただきます。基本的には英語のみということは少なく、生徒さんのご要望や、フィードバックの際に日本語を使うなど、柔軟に対応していただく形になります。
受講生がまったく話せない場合は？
+
焦らず、超初心者向けのアプローチを取りましょう。

• 日本語を交えながらゆっくり進める
• 簡単な表現から始める
• 「リピートアフターミー」形式で練習
• 小さな成功体験を積み重ねる

📝 超初心者向けレッスンを見る
時間内に終わらない場合は？
+
無理に終わらせず、次回に続きをやりましょう。

• 質を重視（量より実践の深さ）
• 中途半端に終わっても大丈夫
• 次回「前回の続きから」でOK

🛠️ トラブル対応・業務

レッスンのレコーディングは、いつからいつまで行えば良いですか？
+
レッスンが始まった時から、終了するまで全ての時間をレコーディングしてください。
Google Meet接続トラブルが発生したら？
+
落ち着いて対処し、必要に応じて運営に連絡してください。

トラブル 対応方法
音声が聞こえない ・マイク・スピーカーの設定を確認
・「マイク」ボタンを押し直す
・デバイスの音量を確認
映像が映らない ・カメラの設定を確認
・「カメラ」ボタンを確認
・他のアプリがカメラを使用していないか確認
接続が不安定 ・Wi-Fi接続を確認
・可能であれば有線接続に切り替え
・一度退出して再接続
受講生が遅刻・欠席した場合は？
+
状況に応じて柔軟に対応してください。

状況 対応方法
遅刻の場合 ・開始時刻から10分までは待機
・10分経過しても連絡がない場合は運営に報告
・途中参加の場合は残り時間で可能な範囲でレッスン
無断欠席の場合 ・10分待機後、運営Slackに報告
・受講生への連絡は運営が行います
体調不良の場合 ・無理せず休憩or振替提案
・振替については運営に相談
録画を忘れてしまった場合は？
+
気づいた時点ですぐに録画開始してください。

• 途中からでも録画を開始する
• レッスン後、運営Slackに報告
• レッスンメモを通常より詳しく記入する

⚠️ 重要 録画は受講生の復習用として重要です。できる限り忘れないよう、レッスン開始時のチェックリストに入れておきましょう。

💰 報酬について

勉強会やミーティングに参加したら報酬はありますか？
+
運営から「依頼」がある場合のみ報酬対象です。

• 運営指定イベント → 報酬あり（都度金額指定）
• 任意の勉強会・視聴 → 報酬なし（自由参加）

詳しくははじめにページの報酬ルールをご覧ください。
指導経験があるのですが、給与を上げていただくことは可能ですか？
+
経験豊富な方でも、初月の給与は一律でスタートさせていただいております。その後、生徒さんの満足度に応じて昇給するシステムとなっております。
給与支払日はいつですか？
+
毎月25日に前月分のレッスン報酬をお支払いします。

（例：1月のレッスン分は2月25日に支払い）
